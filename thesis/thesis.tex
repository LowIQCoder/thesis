\begin{abstract}
Current agentic systems demonstrate outstanding performance
among various types of tasks, including code generation and validation.
However due to probabilistic nature of models, controversial information, and inconsistency in dateset
quality, Large Language Models tend to hallucinate, generating structurally 
correct, but logically false code snippets. Hallucination detections methods
vary in their methodology, however one specific subset stands out among others.
Present papers demonstrated a property of hidden states to store information
related to models awareness. Using this insights it is possible to detect,
but not affect generation of hallucinations. In this paper we plan to investigate
performance of hallucination aware agentic loops. Resulting system will not only
be able to detect hallucinated samples, but also apply this knowledge for 
generation of correct code
\end{abstract}
